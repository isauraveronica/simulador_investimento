As perguntas que a ferramenta responde são:
- Quanto investir por mês;
- Por quantos anos;
- Qual a taxa de rendimento mensal;
- Quanto de patrimônio vai acumular;
- Quanto vai receber de dividendos por mês.

Como o VF e o PROCV entram nos cálculos? 
O VF calcula o valor futuro e a função procv busca uma informação em outra planilha.

Os intervalos nomeados facilitam a montagem das funções.

Os percentuais de cada perfil vieram da tabela de Tipo de FII, que é uma tabela de investimento imobiliário.
